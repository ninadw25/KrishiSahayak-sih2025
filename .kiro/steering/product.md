# Agricultural AI Platform - Product Overview

## Core Purpose
A crop recommendation system that provides AI-powered agricultural insights without database complexity. The platform delivers crop recommendations, fertilizer suggestions, and yield predictions using local premade ML models, LangGraph Agentic ai workflow and live weather APIs.

## Key Features
- **Crop Recommendations**: Rule-based predictions using 7,308+ crop records
- **Weather Integration**: Live weather data via RapidAPI
- **Soil Analysis**: Local soil data with 787+ records
- **Fertilizer Recommendations**: ML-powered fertilizer suggestions
- **Investment Analysis**: Yield estimates and risk factor analysis
- **Seasonal Planning**: Crop season calendar and rotation scoring

## Architecture Philosophy
- **Database-free**: All data sourced from local CSV files
- **Minimal complexity**: Simplified rule-based approach over complex ML
- **API-first**: FastAPI microservices architecture
- **Local-first**: No external database dependencies

## Target Users
Farmers, agricultural consultants, and agricultural technology companies seeking quick, reliable crop recommendations without infrastructure overhead.
